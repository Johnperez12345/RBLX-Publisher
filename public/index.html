SETUP GUIDE

How to get your API key

  1. Open Roblox Creator Dashboard

    Go to create.roblox.com and sign in to your Roblox account.

  2. Open Open Cloud

    Find the Open Cloud section in Creator Dashboard, then open API Keys.

  3. Create a new API key

    Give the key a recognizable name and choose only the permissions needed for the task you intend to perform.

  4. Set the correct experience and permissions

    Choose the relevant experience/resources and the asset or place permissions required by Roblox. The available scopes depend on the publishing feature.

  5. Copy and keep it private

    Copy the key once and paste it into the relevant publisher field. Never share it in chat, screenshots, or public code.

Security note
The Animation Publisher sends the key to the external YuzkPub Worker at yuzkpub-api.galiasnathaniel5.workers.dev. Use a dedicated key with the minimum required permissions. Revoke it in Creator Dashboard if you no longer trust or need that Worker.
