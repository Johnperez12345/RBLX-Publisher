# RBLX Experience Creator — private preview

This folder contains an isolated UI preview for the proposed Create Universe / Create Place feature.

- Open `index.html` locally to inspect the UI.
- This preview does not make Roblox API requests.
- Creation controls are intentionally disabled.
- It does not collect Roblox cookies, API keys, or other credentials.
- Do not merge this branch into `main` or deploy it to the existing live Publisher until the Roblox creation flow is verified and separately approved.

The backend remains locked. The separate `roblox-proxy` Worker is not used or modified by this preview.
